# Datasets

The CSVs are **not tracked** — the repo `.gitignore` excludes `*.csv`, and these three come
to ~148 MB together. Drop them in this directory before running anything in `../src`.

| File | Rows | Columns | Where it comes from |
|---|---|---|---|
| `bccc_darknet.csv` | 25,538 | 475 | Input. The binary BCCC Darknet flow export. |
| `bcc_darknet_labeled_high_confidence.csv` | 24,102 | 476 | Generated by `src/main2.py`. |
| `MultiTotalDS.csv` | 7,921 | 475 | Multi-class variant, kept for reference. |

## `bccc_darknet.csv`

The one you need to supply yourself. 475 columns of per-flow features — identifiers
(`flow_id`, `src_ip`, `dst_ip`, ports, protocol), timing and volume statistics, and a long
tail of `utf8_*_gram_entropy` payload-entropy features.

Its `label` column is `Encrypted` (6,968) / `Non-Encrypted` (18,570). Note this is a traffic
*type* label, not an anomaly label — nothing in the pipeline trains on it. It is only useful
afterwards, for checking what the detected anomalies turned out to be.

A copy of this file is already in the repo at
`ObsoleteExperiments/DataPreprocessing/bccc_darknet.csv`, from the notebook version of the
experiment.

## `bcc_darknet_labeled_high_confidence.csv`

Written by `src/main2.py`, so you don't need to fetch it — regenerate it. It is
`bccc_darknet.csv` with a `pseudo_label` column added (1 = anomaly, 0 = normal) and the
1,436 rows the two detectors disagreed on removed. 23,543 normal / 559 anomalous.

This is the only input `src/supervised.py` reads.

## `MultiTotalDS.csv`

The multi-class version of the same capture, labelled by anonymity network: `ZERONET` (2,327),
`I2P` (2,099), `VPN` (2,081), `TOR` (1,258), `FREENET` (156). No script here uses it — it is
here for the multi-class direction the project did not end up taking.
